Interrogation Taxonomique NCBI Locale (TaxID & Espèces Compagnon 9615, 9685, 9796)

Acteur Souverain : Conseiller Animalier & Propriétaire de l'Animal
Étape 1Sélection de l'espèce animale ou recherche par dénomination vernaculaire dans le module mémoriel animalier.
Étape 2Résolution locale instantanée du taxon dans la base embarquée NCBI Taxonomy (sans appel réseau).
Étape 3Association stricte du TaxID : Canis lupus familiaris (9615), Felis catus (9685), Equus caballus (9796).
Étape 4Vérification croisée avec le numéro de transpondeur RFID (ISO 11784/11785) et l'organisme d'identification (DogID / CatID).
Étape 5Scellement du TaxID dans la structure de données pour verrouiller l'orientation sanitaire Catégorie 1 mémorielle.
Préconditions : Création d'un dossier Sanctuaire mémoriel pour un animal familier de compagnie (canin, félin, équin).
Postconditions : Le TaxID NCBI officiel est scellé dans l'en-tête de la capsule, garantissant le respect strict de la filière sanitaire.
