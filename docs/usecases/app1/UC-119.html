Recherche & Autocomplétion Référentiel Communes / Codes Postaux Belges (Base INS/NIS Statbel)

Acteur Souverain : Conseiller Funéraire & Famille
Étape 1Saisie prédictive des premiers caractères du toponyme ou du code postal belge (ex: '7000' ou 'Mons').
Étape 2Interrogation de la base de données embarquée Statbel (Office belge de statistique) fonctionnant 100% hors-ligne.
Étape 3Affichage instantané des suggestions normalisées avec code INS officiel (ex: 53053 pour Mons, 21004 pour Bruxelles).
Étape 4Sélection de l'entité : renseignement automatique de la province, région linguistique et arrondissement administratif.
Étape 5Association pérenne du code INS dans les actes de transport et de déclaration de crémation/sarcomusation.
Préconditions : Saisie de la commune de décès, de cérémonie funéraire ou de concession de sépulture.
Postconditions : La commune et le code postal sont rigoureusement indexés sur la nomenclature officielle Statbel.
