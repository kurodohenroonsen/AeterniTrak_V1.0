Signature Cryptographique Décentralisée d'un Message du Livre d'Or

Acteur Souverain : Proche ou Membre de la Famille Laissant un Témoignage
Étape 1Saisie de l'hommage et du nom du proche dans le formulaire du Livre d'Or.
Étape 2Génération ou récupération de la paire de clés Ed25519 in-device de l'auteur.
Étape 3Canonisation JSON du message (RFC 8785 JCS - JSON Canonicalization Scheme).
Étape 4Signature cryptographique Ed25519 de l'empreinte SHA-256 via SubtleCrypto (14 ms).
Étape 5Encapsulation dans un Pollen P2P réplicable en Bluetooth LE ou synchronisable lors du retour en réseau.
Préconditions : Proche connecté au sanctuaire local via NFC ou PWA et rédigeant un mot d'adieu.
Postconditions : Message scellé et certifié inaltérable pour les siècles à venir dans la mémoire distribuée.
